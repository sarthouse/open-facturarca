Solución de código abierto para emitir Facturas A, B, C, Notas de Crédito, Remitos y Libros IVA en ARCA (AFIP) para WooCommerce.

== Description ==

Open FacturARCA conecta tu tienda de WooCommerce de forma directa, nativa y segura con los Web Services oficiales de ARCA (WSAA y WSFEV1) en Argentina.

= Características Principales =
* **Resolución Fiscal Inteligente:** Facturas A, B o C automáticas según emisor y receptor.
* **Consulta en tiempo real al Padrón ARCA:** Autodetección de condición de IVA y CUIT sin campos confusos para el cliente.
* **Multi-empresa:** Emite con diferentes CUITs y logos en la misma tienda.
* **Notas de Crédito:** Emisión automática ante reembolsos de WooCommerce.
* **Remitos y Notas de Pedido:** Documentos auxiliares en PDF nativo (Letra X).
* **Libro IVA Ventas y Coeficientes IIBB:** Exportación en CSV listo para Excel.

== Installation ==

1. Sube la carpeta del plugin al directorio `/wp-content/plugins/` o instala el archivo ZIP desde **Plugins > Añadir nuevo**.
2. Activa el plugin a través del menú **Plugins** en WordPress.
3. Dirígete a **WooCommerce > Ajustes > Open FacturARCA** para configurar tu CUIT y certificados.

== Frequently Asked Questions ==

= ¿Tiene costo mensual por factura? =
No. Open FacturARCA es 100% libre y de código abierto. Te comunicas directamente con los servidores de ARCA sin pagar intermediarios.

= ¿Requiere librerías externas para PDF? =
No. El plugin incluye un generador de PDF binario nativo y ultraliviano en PHP puro.
